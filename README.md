PocketSmart AI – Smart Budget & Recommendation Assistant

📌 Project Overview

PocketSmart AI is a GenAI-powered budget planning and recommendation assistant that helps users make smart, budget-friendly decisions for everyday needs. The system analyzes the user's budget, preferences, requirements, and optional images to generate personalized recommendations.

The project supports three major planning areas:

- 🏠 Home Interior Planning – Furniture, lighting, decoration, and other home essentials.
- 🎉 Party Planning – Food, venue, decoration, and entertainment based on budget and guest count.
- 💎 Jewelry Planning – Jewelry recommendations based on budget, occasion, style, and optional outfit images.

The system uses Gemini 1.5 Flash Pro for AI-powered analysis and recommendations, with a FastAPI backend and a web-based frontend. It can provide recommendations from platforms such as Amazon, Flipkart, IKEA, Swiggy, Zomato, and OYO.

🚀 Project Phases

Phase 1 – AI Setup & Initialization

- Set up Gemini API and required credentials.
- Configure API access and permissions.
- Test text and image-based AI inputs.
- Create prompts for budget-based recommendations.

Phase 2 – Core Functionality Development

- Develop the main recommendation logic.
- Implement Home, Party, and Jewelry planners.
- Process user budgets and preferences.
- Integrate Gemini AI with the application.

Phase 3 – Backend Development

- Develop the FastAPI backend.
- Create API routes for each planner.
- Implement authentication and session management.
- Connect the backend with the AI recommendation engine.

Phase 4 – Platform & Recommendation Integration

- Integrate product and service sources.
- Connect platforms such as Amazon, Flipkart, IKEA, Swiggy, Zomato, and OYO.
- Generate recommendations according to user budget and requirements.
- Display detailed recommendation results.

Phase 5 – UI Development

- Design the web interface using HTML, CSS, and Jinja2.
- Create planner forms for Home, Party, and Jewelry.
- Display recommendations in structured layouts.
- Develop Home, Login, Register, and Dashboard pages.

Phase 6 – Authentication & Personalization

- Implement user registration and login.
- Add JWT-based authentication.
- Manage user sessions.
- Provide personalized recommendations based on user data.

Phase 7 – Testing & Optimization

- Test different budgets and user requirements.
- Test all three planning modules.
- Evaluate AI recommendation quality.
- Improve prompts, validations, and fallback recommendations.
- Optimize the overall user experience.

Phase 8 – History & Final Integration

- Store and display previous recommendation results.
- Allow users to review previous plans.
- Integrate all project modules.
- Finalize the complete AI-powered budget recommendation system.
